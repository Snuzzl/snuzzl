# Tasks

The Tasks feature lets users manage their daily schedule through both custom tasks they create themselves and predefined tasks from a built-in catalog.

## Custom Tasks

Users can create their own tasks with a name and optional description. Once created, a custom task can be assigned to a specific date and time slot. Custom tasks can be edited, rescheduled, marked complete or incomplete, and deleted when no longer needed.

## Predefined Tasks

The app includes a catalog of predefined tasks organised by category — such as Exercise, Cleaning, Self Care, Work, Food/Drinks, and Downtime. Users can browse the catalog, assign tasks to their schedule, and manage them just like custom tasks. Unassigning a predefined task removes it from the user's schedule without deleting it from the catalog.

## Task Management

All assigned tasks appear in the user's task list with their scheduled date and time, completion status, and category. Tasks can be toggled between complete and incomplete, and their schedule can be updated at any time.
