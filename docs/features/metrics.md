# Metrics

The Metrics feature lets users view and update metrics being tracked by the system.  

There are five core metrics that can be viewed but are only updated by completing [tasks](tasks.md).  
The core metrics are:  
- Productivity: How productive the user is  
- Emotional Health: How the user is looking after their mental wellbeing  
- Physical Health: How the user is eating and exercising, their physical wellbeing  
- Rest: How much rest and relaxation the user is getting  
- Lifestyle: The kind of habits a user has, general wellbeing

Metrics that are updated by the user are:  
- Sleep length  
- Sleep quality  
- Motivation  
- Feeling  
- Screentime  
- Steps  
- Calories  

## Wellbeing Score

The Wellbeing Score is a value that is calculated using all the metric values for a user.
It is a reflection of their interaction with the apps features, giving them an indicator for where they can improve their wellbeing.
