# Accounts

Accounts are a supporting feature that enable the app to function for more than one concurrent user.  
Allowing users to login means the system can use their user id to track the application state.

Accounts have:  
- A username  
- A password  
- An email address  
- A first name  
- A date of birth

The username, password and email for an account can be changed.  
Accounts can be deleted.
